# Отчёт о проверках

- **Один контейнер.** Сборка и запуск прошли успешно. `GET /` вернул `count: 0` и заданное приветствие. После `POST /increment` счётчик стал равен `1`. В журнале приложения были ответы `200`.
- **Compose с SQLite.** После `docker compose down` и `docker compose up -d` счётчик остался равен `1`, хотя контейнер был пересоздан.
- **Compose с Redis.** Счётчик сохранил значение `1` после пересоздания контейнеров. При остановленном Redis `/healthz` вернул `200`, а `/readyz`, `GET /` и `POST /increment` вернули `503`. После запуска Redis `/readyz` снова вернул `200`, а следующий `POST /increment` увеличил счётчик с `1` до `2`.

Для повторения проверок с Redis используется `bash scripts/check.sh`.
